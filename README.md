# Minha Jornada em Python

Bem-vindo(a) ao meu repositório de evolução! Este espaço foi criado para documentar e demonstrar o meu progresso na **lógica de programação** e na **construção de códigos** utilizando a linguagem **Python**.

Aqui partilho exercícios, projetos práticos e desafios que me ajudam a evoluir diariamente.

---

## Objetivos do Repositório

* **Praticar a lógica:** Desenvolver o raciocínio lógico para resolver problemas complexos de forma eficiente.
* **Escrever código limpo:** Aplicar boas práticas de programação e organização de código.
* **Registar a evolução:** Criar um histórico visual do meu crescimento técnico ao longo do tempo.

---

## Tecnologias e Ferramentas

* **Linguagem Principal:** Python 3.13.7
* **Ambiente de Desenvolvimento:** VS Code / AutoPyGui
* **Controlo de Versões:** Git e GitHub

---

## Estrutura do Repositório

O código está organizado da seguinte forma:

* `basico/` - Conceitos iniciais, variáveis, estruturas condicionais e repetições.
* `intermediario/` - Funções, listas, dicionários e manipulação de ficheiros.
* `projetos/` - Pequenas aplicações e scripts práticos do dia a dia.
